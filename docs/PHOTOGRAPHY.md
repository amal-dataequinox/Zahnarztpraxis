# Photography guidelines

Real client photography is provided (SDN Fotografie pack). Never generate fake staff, patients or clinic interiors.

## Subject matter

| Category | Intent |
| --- | --- |
| Practice interiors | Calm, daylight, material honesty (wood, stone, soft neutrals) |
| Team portraits | Authentic, unforced; names and titles from CMS only |
| Treatment context | Clinical clarity without fear aesthetics |
| Landscape / place | Appenzellerland atmosphere for Alpine Modernism moments |

## Technical preferences

- Prefer landscape **3:2** for editorial bands; portraits **3:4** for team.
- Leave breathing room for typography — avoid busy faces in crop-critical corners.
- Colour grade toward cool chalk / fir harmony; do not push warm Instagram filters.
- Always provide meaningful German `alt` text in Payload Media.

## Usage in the design system

- Frame images with `MediaFrame` (aspect + optional caption).
- Do not place floating badges or promo stickers on photography.
- Hero photography in Phase 3 should be full-bleed or edge-to-edge where the composition calls for it — not inset collage cards.

## CMS

Upload through Payload **Medien**. Required: localised `alt`. Responsive WebP sizes (`thumbnail`, `card`, `hero`) are generated automatically.
