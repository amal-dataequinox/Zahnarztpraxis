## Type

`--font-sans` / `--font-display` → IBM Plex Sans (`--font-ibm-plex-sans`)

## Cyan budget

Approximately **2–4%** of visible UI on a typical desktop viewport. Max one filled primary CTA per major composition. No cyan section backgrounds.
